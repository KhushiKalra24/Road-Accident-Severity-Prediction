# Road Accident Severity Prediction

A machine learning-based web application that predicts the severity of road accidents based on user-provided accident conditions. The application uses Python and Flask to connect a trained ML model with a simple web interface.

## Project Overview

Road accidents can have different levels of severity depending on several conditions. This project aims to estimate accident severity using a machine learning model.

Users enter the required accident details through a web interface and receive a predicted severity result.

## Features

- User-friendly web interface
- Machine learning-based severity prediction
- Flask backend for model integration
- Prediction probability display
- HTML, CSS and JavaScript frontend

## Tech Stack

| Technology | Purpose |
